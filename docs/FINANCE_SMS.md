# ماژول مالی و پیامک بانکی — نسخه ۱٫۰ رهیار AI

## مدل داده (Prisma — افزونه، بدون تغییر مدل‌های قبلی)

```
FinanceAccount   نام | نوع (cash|bank|card) | مانده افتتاحیه | ارز (IRR) | archived
FinanceTransaction  نوع (income|expense|transfer) | مبلغ (ریال، همیشه مثبت) |
                    حساب مبدأ | حساب مقصد (فقط انتقال) | دسته | یادداشت |
                    زمان رخداد | منبع (manual|sms|import) | externalRef (ضدتکرار)
FinanceBudget      دسته هزینه | سقف ماهانه — @@unique([userId, category])
```
- `@@unique([userId, externalRef])` → پیامک تکراری هرگز دو بار ثبت نمی‌شود (هش SHA-256 متن پیامک)
- همه پرس‌وجوها scope کاربر (`userId`) — جداسازی کامل

## API

| مسیر | متدها | توضیح |
|---|---|---|
| `/api/finance/accounts` | GET/POST | فهرست با مانده محاسبه‌شده / ساخت حساب |
| `/api/finance/accounts/[id]` | PATCH/DELETE | ویرایش/حذف (حذف = حذف تراکنش‌هایش) |
| `/api/finance/transactions` | GET/POST | فیلتر ماه (`?month=YYYY-MM`) و نوع / ثبت |
| `/api/finance/transactions/[id]` | PATCH/DELETE | ویرایش/حذف |
| `/api/finance/budgets` | GET/PUT/DELETE | بودجه ماهانه دسته‌ها + وضعیت مصرف ماه جاری |
| `/api/finance/export` | GET | `?format=csv\|xls\|json\|txt` + `month` (JSON/TXT شامل بودجه‌ها) |
| `/api/sms/import` | POST | تحلیل پیامک — دو مرحله‌ای (پیش‌نمایش/ثبت) |

همه با: نشست اجباری، same-origin، rate limit، سقف بدنه، پیام خطای فارسی شفاف.

## محاسبات خالص و آزمون‌شده (`src/lib/finance/core.ts` + `src/lib/finance/budget.ts`)
- مانده حساب = افتتاحیه + درآمد − هزینه ± انتقال (دوسویه)
- خلاصه ماه: درآمد/هزینه/خالص + byCategory + byDay (انتقال در خالص حساب نمی‌شود)
- قالب مبلغ دوزبانه (ریال/تومان × IRR/Toman — قابل انتخاب در تنظیمات ← مالی)
- بودجه: مصرف هر دسته فقط از «expense» همان ماه؛ warn ≥۸۰٪، over = عبور از سقف — ۸ آزمون واحد

## بودجه ماهانه (تازه نسخه ۱٫۰ RC)
- کارت «بودجه ماهانه» در نمای مالی: سقف هر دسته هزینه + نوار مصرف (سبز/کهربایی/سرخ) + جمع کل
- UI: انتخاب دسته + سقف → PUT upsert؛ حذف با دکمه هر سطر؛ وضعیت زنده از GET
- منطق خالص در `src/lib/finance/budget.ts` — کاملاً قطعی و بدون مدل

## خروجی‌ها
- **CSV**: UTF-8 + BOM (اکسل فارسی مستقیم باز می‌کند)
- **Excel**: SpreadsheetML 2003 (`.xls`) با دو شیت «تراکنش‌ها» و «حساب‌ها»
- **JSON / TXT**: کامل و خوانا
- **PDF**: از خود نمای گزارش با چاپ مرورگر (Ctrl/Cmd+P) — تنها راه تضمین رندر صحیح RTL فارسی بدون وابستگی سنگین؛ دکمه راهنما در UI هست

## دسته‌بندی‌ها
هزینه: خوراک، حمل‌ونقل، مسکن، قبوض، خرید، سلامت، آموزش، تفریح، خانواده، خیریه، متفرقه
درآمد: حقوق، پروژه، هدیه، سود، فروش، متفرقه — برچسب‌ها دوزبانه از i18n.

## پیامک بانکی (اندروید/web) — فقط با رضایت
1. **رضایت صریح**: سوییچ «رضایت تحلیل پیامک» (Setting: `sms_consent`) — بدون آن ثبت ممکن نیست
2. **پارسر قطعی** (`src/lib/sms/parser.ts`، خالص و ۷ آزمون‌شده):
   - نرمال‌سازی ارقام فارسی/عربی + جداکننده هزارگان (٬ U+066C)
   - تشخیص ~۲۰ بانک اصلی ایران (ملت، ملی، صادرات، پارسیان، پاسارگاد، سامان، …)
   - فعل (واریز/برداشت/خرید/انتقال/کارمزد/سود) → income/expense
   - مبلغ (ریال؛ تومان صریح ×۱۰)، موجودی، کارت ماسک‌شده (`6104****1234`)، تاریخ شمسی/میلادی + ساعت
   - استراتژی دومرحله‌ای: خط مستقل کامل ← ادغام خط‌های ناکام (پیامک چندخطی)
3. **پیش‌نمایش → تأیید کاربر** → ثبت با منبع `sms` و ضدتکرار هش
4. **اندروید (آینده)**: مجوز RECEIVE_SMS فقط با اپ همراه؛ پردازش محلی روی گوشی؛ مسیر رسمی مستند در اتصال‌ها

## حریم خصوصی
متن خام پیامک ذخیره نمی‌شود؛ فقط تراکنش استخراج‌شده + هش. هیچ داده مالی به مدل یا سرویس بیرونی نمی‌رود. حذف کامل از تنظیمات ← حریم خصوصی (حق فراموشی).
