## ۲. ممیزی امنیتی و ایمن‌سازی (بخش ۴)

**یافته محوری:** اپ **تک‌کاربره بدون احراز هویت** بود (اسکیما بدون User/Session؛ همه داده جهانی).
طبق معیار توقف دستور: **انتشار عمومی مجاز اعلام نمی‌شد** → پیاده‌سازی کامل انجام شد:

- مدل‌های `User`, `Session`, `AiUsage`, `ActionLog` + ستون `userId` (NOT NULL در DB) روی Task/Reminder/ChatMessage/Memory/Setting
- مهاجرت ۲فازی بدون از دست رفتن داده (بکاپ `ara-20261017-063007.db` → push فاز A → backfill → push فاز B) — راستی‌آزمایی: صفر رکورد بی‌صاحب، ۶ کار/۱ یادآور/۳ چت/۱ حافظه حفظ شد
- scrypt (N=16384) + timingSafeEqual؛ توکن ۳۲ بایتی، در DB فقط SHA-256
- کوکی `rahyar_session`: httpOnly + sameSite=lax + secure در تولید + انقضای ۳۰ روز
- گیت دولایه: middleware (حضور کوکی) + `requireUser()` در ۱۲ مسیر API (اعتبارسنجی واقعی DB)
- ورود: سقف ۱۰/دقیقه، پیام عمومی بدون افشای وجود حساب؛ خروج: حذف رکورد + انقضای کوکی
- هرس نشست منقضی در زمان‌بند سرور
- **باگ امنیتی کشف‌شده با آزمون واحد:** هش خراب/خالی هر رمزی را می‌پذیرفت → رفع شد (گارد طول salt/hash)
- اسرار در تاریخچه گیت: از نشست قبلی معلوم بود `.env`/db قبلاً track بودند؛ فقط `DATABASE_URL` در تاریخچه؛ هیچ کلید API — توصیه: پاک‌سازی تاریخچه فقط با تأیید مالک، پیش از هر push (تاریخچه دست نخورد)

## ۴. معماری AI کم‌هزینه (بخش ۶)

- **AI Gateway مرکزی** (`src/lib/ai/gateway.ts`): تنها مسیر مدل؛ مسیر `chat/stream` که مستقیماً SDK را صدا می‌زد مهار و به Gateway منتقل شد
- ترتیب گاردها: کلید قطع → سقف ورودی → سهمیه (کاربر/روز=۶۰، کاربر/ماه=۹۰۰، سامانه/روز=۳۰۰؛ env قابل تغییر؛ ۰=بی‌سقف) → اجرا با حداکثر ۱ retry گذرا → ثبت مصرف
- **کلید قطع اضطراری:** `RAHYAR_AI_DISABLED=1` یا Setting `ai_kill_switch=1` — **آزمون زنده شد:** چت عمومی با کلید روشن → «هوش مصنوعی موقتاً غیرفعال است…» بدون فراخوانی مدل
- ثبت `AiUsage` فقط فراداده (route/task/model/chars/latency/status) — هیچ متن خصوصی
- سهمیه تمام → پیام شفاف فارسی + ادامه امکانات بدون مدل؛ هیچ مسیر پولی مخفی
- **مسیریاب قطعی** (`assistant/router.ts`): ثبت کار/گزارش روز/لیست بدون مدل — آزمون زنده: `mode: deterministic`
- آزمون‌ها: ۲۱ آزمون Gateway/مسیریاب (سقف‌ها، اولویت گاردها، ۰=بی‌سقف، خطای گذرا، پیام فارسی)

## ۵. دستیار اجرایی (بخش ۷)

- ثبت زبان‌طبیعی قطعی با پارسر فارسی موجود (تاریخ/ساعت/اولویت/تکرار/#برچسب)
