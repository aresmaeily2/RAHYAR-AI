# ماتریس تطبیقی کامل قابلیت‌ها — RahyAr v2.0.0

**تاریخ:** 2026-10-21 | **قرارداد واژگان:** «تکمیل و تأییدشده» = کد + آزمون واقعی اجراشده + شواهد زنده؛ «پیاده‌سازی‌شده اما آزموده‌نشده روی دستگاه» = کد + آزمون JVM/زندهٔ سرور، بدون دستگاه فیزیکی؛ «صرفاً طراحی‌شده» = سند، بدون کد متصل.

**محدودیت محیطی سراسری:** در محیط ساخت این جلسه **دستگاه اندروید فیزیکی، adb و شبیه‌ساز (KVM) وجود ندارد**. بنابراین هیچ قابلیتی از سوی ما «آزموده‌شده روی دستگاه» اعلام نمی‌شود. قابلیت‌های اندروید در بالاترین سطح ممکن این محیط (کد + آزمون JVM + build موفق + badging) تحویل شده و چک‌لیست آزمون دستگاهی برای مالک ارائه شده است.

## چک‌لیست آزمون دستگاهی مالک (۱۵ دقیقه)

1. نصب دو APK (هر دو کنار هم نصب می‌شوند — شناسهٔ بسته متفاوت).
2. ورود با آدرس سرور + حساب؛ بررسی صفحات: امروز/کارها/تقویم/دستیار/برنامه/مالی/تنظیمات.
3. چت: بپرس «امروز چه کارهایی دارم؟» — پاسخ مدل + اکشن‌ها.
4. صدا: دکمهٔ میکروفون ← بگو «یک کار جدید اضافه کن خرید نان» ← ثبت شود؛ دکمهٔ پخش ← خواندن پاسخ.
5. یادآور: یادآوری ۲ دقیقه بعد بساز ← مجوز اعلان را «اجازه» بده ← اپ را ببند ← اعلان سیستم بیاید.
6. ری‌استارت گوشی قبل از یادآوری بعدی ← اعلان باز هم بیاید (BootReceiver).
7. حالت پرواز ← پیام خطای اتصال اپ ← اتصال ← بازیابی.
