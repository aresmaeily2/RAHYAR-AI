# راهنمای نصب و راه‌اندازی — RahyAr v2.0.0

## گام ۱ — نصب اپ

| فایل | برای | شناسهٔ بسته |
|---|---|---|
| `RahyAr-User-v2.0.0-debug.apk` | کاربر عادی | `com.rahyarai.app` |
| `RahyAr-Owner-v2.0.0-owner-debug.apk` | مالک | `com.rahyarai.app.owner` |

- هر دو روی یک گوشی کنار هم نصب می‌شوند. اندروید ۷٫۰ (API 24) به بالا.
- اگر هشدار «منبع ناشناس» آمد: تنظیمات ← نصب اپ‌های ناشناس ← اجازه برای مرورگر/فایل‌منیجر.
- برچسب اپ پس از نصب: «رهیار» / «رهیار مالک».

## گام ۲ — اتصال به سرور

1. اپ را باز کنید — صفحهٔ «ورود به رهیار» نمایش داده می‌شود.
2. در فیلد **آدرس سرور**، نشانی HTTPS سرور رهیار را وارد کنید (یک‌بار؛ به خاطر سپرده می‌شود).
3. نام کاربری/رمز خود را وارد کنید (ویراست مالک، نام کاربری از پیش «owner» است — رمز را خودتان وارد کنید؛ هیچ رمزی در APK نیست).
4. «ورود» ← صفحهٔ اصلی کامل محصول (دستیار، کارها، تقویم، مالی، برنامه، تنظیمات).

## گام ۳ — رضایت‌ها (اختیاری و شفاف)

- **اعلان یادآور:** نخستین باری که یادآوری می‌سازید، توضیح نمایش داده می‌شود ← «اجازه می‌دهم» = اعلان سیستمی حتی با اپ بسته؛ «خیر» = فقط هشدار داخل برنامه.
- **زنگ دقیق:** برای ثانیه‌دقیق بودن، یک‌بار مسیر تنظیمات سیستم پیشنهاد می‌شود؛ «بعداً» = اعلان شاید چند دقیقه دیرتر.
- **میکروفون:** دکمهٔ میکروفون در چت ← تشخیص گفتار روی دستگاه (صدا به هیچ سروری نمی‌رود).

## گام ۴ — حالت محلی آفلاین (جایگزین)

در پایین صفحهٔ ورود، لینک «حالت محلی آفلاین» هست: چهار صفحهٔ محلی (خانه/وظایف/یادآورها/تنظیمات) بدون سرور و بدون حساب — برای مواقع بدون اینترنت. این حالت **محصول کامل نیست**؛ محصول کامل حالت متصل است.

## استقرار سرور (پیش‌نیاز حالت متصل)

راهنمای کامل: `DEPLOYMENT_V2_FA.md` — خلاصه:
```bash
git clone <repo> rahyar && cd rahyar
cp .env.example .env      # DATABASE_URL و RAHYAR_SETUP_TOKEN
bun install && bun run db:push && bun run build
PORT=3000 NODE_ENV=production bun .next/standalone/server.js
# مرورگر → /login → «راه‌اندازی اولیه» با توکن → حساب مالک
```

## عیب‌یابی سریع

| نشانه | علت/راه‌حل |
|---|---|
| «آدرس سرور نامعتبر» | فقط https عمومی پذیرفته می‌شود (localhost/IP خصوصی بسته است) |
| صفحهٔ «سرور در دسترس نیست» | سرویس سرور خاموش است یا اینترنت قطع است ← «تلاش دوباره» |
| پاسخ دستیار «سهمیه…» | سهمیهٔ روز/ماه پر شده — یا صبر یا در تنظیمات←AI کلید شخصی (Endpoint سازگار با OpenAI) |
| اعلان نمی‌آید | مجوز اعلان در تنظیمات اندروید برای اپ رد شده باشد ← فعال کنید |
