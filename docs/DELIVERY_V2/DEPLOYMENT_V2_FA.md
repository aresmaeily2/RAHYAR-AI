# راهنمای استقرار و عملیات — RahyAr v2.0.0 (سرور محصول کامل)

## پیش‌نیازها
- هر هاست Node (bun 1.3+ یا Node 20+)، ~۲۵۰MB دیسک، پورت عمومی پشت TLS
- دامنهٔ HTTPS (برای اپ اندروید اجباری — کلاینت فقط https عمومی می‌پذیرد)

## گام‌به‌گام
```bash
git clone <repo> rahyar && cd rahyar
cp .env.example .env
bun install
bun run db:generate && bun run db:push
bun run build
PORT=3000 NODE_ENV=production bun .next/standalone/server.js
```

## متغیرهای محیطی کلیدی

| متغیر | ضروری؟ | توضیح |
|---|---|---|
| `DATABASE_URL` | بله | `file:<مسیر مطلق>/db/custom.db` |
| `RAHYAR_SETUP_TOKEN` | توصیه‌شده (production) | توکن یک‌بارمصرف راه‌اندازی مالک — بدون آن، setup در production 503 می‌دهد |
| `TRUST_PROXY_HEADERS` | پشت پروکسی = ۱ | وگرنه rate-limit با هدر جعلی دور زده می‌شود |
| `RAHYAR_AI_DISABLED` | اختیاری | `1` = قطع همهٔ فراخوانی‌های مدل (قواعد محلی زنده می‌ماند) |
| `AI_USER_DAILY_LIMIT` / `AI_USER_MONTHLY_LIMIT` / `AI_SYSTEM_DAILY_LIMIT` | اختیاری | پیش‌فرض ۶۰/۹۰۰/۳۰۰ (۰ = بی‌سقف — توصیه نمی‌شود) |
| `AI_MAX_INPUT_CHARS` / `AI_MAX_OUTPUT_CHARS` | اختیاری | پیش‌فرض ۲۴۰۰۰/۴۰۰۰ |

## فعال‌سازی «مدل میزبان» (چت AI واقعی بدون کلید کاربر)

معماری: فراخوانی مدل فقط از Gateway سرور انجام می‌شود. موتور `zai` وقتی روی هاست، فایل پیکربندی رسمی SDK (`/etc/.z-ai-config` یا `~/.z-ai-config` یا `cwd/.z-ai-config` یا مسیر `ZAI_CONFIG_PATH`) موجود باشد «آماده» اعلام و به‌عنوان موتور پیش‌فرض کاربران انتخاب می‌شود؛ در غیر این صورت شفاف به «قواعد محلی» سقوط می‌کند.

**شرایط عملیاتی پیش از استفادهٔ عمومی** (طبق بند ۳ دستور):
1. مجوز استفاده از سرویس مدل میزبان را برای استقرار عمومی بررسی کنید (شرایط سرویس، سقف مصرف، محرمانگی).
2. سهمیه‌های بالا را متناسب با تعداد کاربران تنظیم کنید.
3. در تنظیمات اپ (تنظیمات ← هوش مصنوعی) وضعیت «مدل میزبان» و تست اتصال برای هر کاربر قابل مشاهده است.

**جایگزین/مکمل:** هر Endpoint سازگار با OpenAI (OpenAI/DeepSeek/OpenRouter/Ollama/LM Studio) — کاربر در تنظیمات URL/مدل/کلید خودش را وارد می‌کند؛ کلید فقط سمت سرور او ذخیره و فقط ماسک نمایش داده می‌شود.

## راه‌اندازی اولیهٔ مالک
```bash
RAHYAR_SETUP_TOKEN=$(openssl rand -hex 24)   # در .env بگذارید و سرویس را ری‌استارت کنید
```
مرورگر ← `https://دامنه/login` ← «راه‌اندازی اولیه» ← نام کاربری `owner` + رمز قوی (≥۸). این مسیر فقط یک‌بار باز است؛ سپس توکن را از `.env` حذف کنید.

## عملیات
- سلامت: `GET /api/health` (مناسب uptime monitor)
- پشتیبان: `bun run backup` (VACUUM INTO + integrity) — نگهداری خارج از سرور
- به‌روزرسانی: `git pull → bun install → db:push → build → ری‌استارت`؛ داده کاربر دست‌نخورده
- لاگ: stdout پروسه — بدون محتوای خصوصی کاربر
- مقیاس: تک‌نمونه‌ای (rate-limit و زمان‌بند درون‌حافظه‌ای)

| اعلان/الارم | رایگان (محلی) |
