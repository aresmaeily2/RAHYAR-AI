## کجا چه نامی می‌آید

### شناسه‌های فنی (ara) — عمداً دست‌نخورده می‌مانند
طبق دستور مالک، این‌ها فقط برای یکسان‌سازی ظاهری تغییر نمی‌کنند:

| شناسه | مقدار | دلیل حفظ |
|--------|-------|-----------|
| نام پکیج npm | `rahyar` | تغییرش مزیت ظاهری ندارد و ریسک وابستگی/ابزار را بالا می‌برد |
| نام پوشه مخزن | `/home/z/my-project` | مسیر استقرار و ابزارها به آن گره خورده |
| نام فایل دیتابیس | `db/custom.db` | مهاجرت نام فایل بدون منفعت است |
| پیشوند کلاس‌های CSS | `ara-*` (مثل `ara-glass`, `ara-float`) | تغییر گسترده بدون منفعت، ریسک رگرسیون بصری |
| نام کامپوننت‌ها | `src/components/ara/*` | شناسه کد، نه رابط کاربر |
| ذخیره محلی جلوه‌ها | `localStorage['ara-effects']` | کلید داخلی، نامرئی برای کاربر |

**قاعده:** اگر رشته‌ای «به کاربر نمایش داده می‌شود» → رهیار AI. اگر «شناسه فنی/داخلی» است → همان `rahyar` می‌ماند و این سند مرجع است.
