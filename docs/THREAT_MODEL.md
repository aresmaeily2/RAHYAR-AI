# مدل تهدید رهیار AI

چارچوب: STRIDE + OWASP Top-10 برای اپلیکیشن‌های LLM (۲۰۲۵).
دامنه: استقرار شخصی تک‌کاربره پشت پروکسی Caddy؛ حساب مالک با رمز scrypt.

## دارایی‌ها

1. داده شخصی کاربر (کارها، یادآورها، حافظه، گفتگو) — محرمانه
2. رمز/نشست مالک — احراز هویت
3. سهمیه مدل/هزینه — اقتصاد سامانه
4. اعتبار پاسخ مدل — صحت عاملیت

## ماتریس تهدید → دفاع → وضعیت

| # | تهدید (STRIDE/LLM) | دفاع پیاده‌شده | وضعیت | باقی‌مانده صادقانه |
|---|---|---|---|---|
| T1 | جعل هویت (S) | نشست کوکی httpOnly/lax/secure، توکن ۳۲بایتی، ذخیره فقط sha256، scrypt+timingSafeEqual، سقف ۱۰/min ورود، هم‌ترازی زمان (burnPasswordTiming) | مهارشده | بازیابی رمز ایمیل ندارد (استقرار شخصی — بازنشانی دستی سرور) |
| T2 | دستکاری درخواست (T) | CSRF: `sameOriginOk` (Origin + `sec-fetch-site: cross-site`) روی همه متدهای تغییردهنده؛ CSP با nonce | مهارشده | — |
| T3 | انکار (R) | ActionLog نتیجه هر اقدام + AiUsage فراداده هر فراخوانی مدل | مهارشده | لاگ دیسکی ماندگار/خارجی وجود ندارد |
| T4 | افشای اطلاعات (I) | همه کوئری‌ها scoped به `userId`؛ بین‌کاربری → ۴۰۴؛ بدون استک‌ترِیس به کلاینت؛ راز فقط در `.env` (untracked) | مهارشده | بلاب‌های تاریخی `.env/db` در تاریخچه گیت (بدون کلید API) — پاک‌سازی نیازمند تأیید مالک |
| T5 | حملات نرخ/DoS (D) | rateLimit پنجره لغزان per-IP×مسیر + سقف بدنه استریمی ۱۰۰KB + سقف سراسری AI 30/min + جستجو 20/min | مهارشده | لیمیتر درون‌حافظه‌ای تک‌نمونه‌ای؛ چندنمونه‌ای نیاز به استور مشترک دارد |
| T6 | ارتقای سطح دسترسی (E) | گارد دولایه (middleware + requireUser)؛ `TRUST_PROXY_HEADERS` قابل غیرفعال‌سازی | مهارشده | — |
| L1 | تزریق پرامپت مستقیم/غیرمستقیم (LLM01) | دیوار `<user_data>` + قانون سخت‌گیرانه در پرامپت سیستم؛ آزمون زنده مستقیم/غیرمستقیم PASS | مهارشده (آزمون‌شده) | دفاع پرامپتی مطلق نیست — خروجی مدل همیشه مهار طول و بدون اجرای HTML است |
| L2 | افشای داده در پرامپت (LLM06) | فقط داده کاربر جاری در زمینه؛ حافظه/کارها scoped | مهارشده | — |
| L3 | اقدام خطرناک مدل (LLM06) | حذف/فراموشی فقط با فعل صریح؛ اکشن‌ها مهارشده ≤۸؛ idempotency با کلید کلاینت | مهارشده | — |
| L4 | مصرف بی‌کران (LLM10) | دروازه: سهمیه کاربر/روز/ماه + سامانه/روز در DB؛ سقف ورودی ۲۴k؛ سقف خروجی ۴k (شامل استریم با قطع upstream)؛ کلید قطع اضطراری؛ مسیر قطعی بدون مدل | مهارشده | fallback پولی وجود ندارد و عمداً خاموش است |
| L5 | URL/محتوای آلوده وب (LLM05) | فقط http/https (`safeUrl`)؛ زمینه وب داخل `<user_data>`؛ مهار طول ۳۲۰/آیتم | مهارشده | — |
| X1 | XSS ذخیره‌شده | رندر با react-markdown بدون rehype-raw؛ CSP nonce + strict-dynamic | مهارشده | — |
| C1 | کلیک‌جک | `frame-ancestors 'none'` + X-Frame-Options DENY | مهارشده | — |

## ریسک‌های پذیرفته‌شده (شفاف)

- استقرار شخصی تک‌نمونه‌ای: چندنمونه‌ای بدون تغییر لیمیتر مجاز نیست.
- جستجوی وب و مدل هر دو به سرویس پلتفرمی وابسته‌اند؛ قطع سرویس → پیام شفاف، امکانات قطعی کار می‌کنند.
- پاک‌سازی تاریخچه گیت فقط با تأیید صریح مالک و قبل از هر push انجام می‌شود.
