# فهرست کامل تغییرات — نسخه ۱٫۰ رهیار AI

## ۱) معماری AI Provider (اولویت ۲)
- `src/lib/ai/providers/types.ts` — قرارداد `AIProvider` + `ProviderCapabilityError/ProviderConfigError` + اعتبارسنجی URL
- `src/lib/ai/providers/builtin.ts` — سهمیه داخلی میزبان (پیش‌فرض رایگان)
- `src/lib/ai/providers/local-rules.ts` — موتور قواعد محلی (بدون مدل؛ پاسخ دوزبانه قطعی)
- `src/lib/ai/providers/openai-compatible.ts` — هر Endpoint سازگار با OpenAI (Ollama/LM Studio/DeepSeek/OpenRouter/…) + تست اتصال
- `src/lib/ai/providers/registry.ts` — ثبت‌کننده + `resolveEngine(userId)` + وضعیت ماسک‌شده کلید
- `src/lib/ai/gateway.ts` — refactor کامل: موتور فعال از تنظیمات؛ سهمیه فقط برای Providerهای مدل؛ خطاهای `GatewayLocalOnlyError/GatewayConfigError`؛ ثبت مصرف با provider/model واقعی
- API: `/api/settings/ai` (GET/PUT + killSwitch)، `/api/settings/ai/test`، `/api/settings/ai/usage`
- fallback قطعی: برنامه روزانه قاعده‌محل (`assistant/rule-plan.ts`) در حالت local_rules

## ۲) دستیار صوتی و Agent (اولویت ۱)
- `src/lib/voice/speech.ts` — Web Speech محلی: شنود fa-IR/en-US + خواندن پاسخ + توقف + تشخیص صدا؛ صدا هرگز ارسال/ذخیره نمی‌شود
- `src/lib/assistant/router.ts` — نیت‌های تازه دوزبانه: `complete_task` (استخراج هدف)، `start_focus`، `help` + الگوهای انگلیسی؛ رفع باگ `\b` با فارسی
- `src/lib/assistant/match.ts` — تطبیق فازی عنوان (توکن + زیررشته + آستانه ۰٫۵) — آزمون‌شده
- مسیر چت استریم: اجرای قطعی complete_task (تکمیل واقعی + ActionLog)، start_focus (اکشن کلاینتی → باز شدن تایمر پومودورو)، help
- chat-view: میکروفون lang-aware، پاسخ گفتاری خودکار پس از دستور صوتی، اجرای start_focus، انسجام با AmbientEngine (orb)

## ۳) i18n دوزبانه (اولویت ۳)
- `src/i18n/{core,fa,en,store,date}.ts` — الگوی کلید طبیعی (gettext): فارسی مبنا + دیکشنری انگلیسی ~۳۹۰ رشته + همگام‌سازی سرور + dir/lang روی html + اعداد
- مهاجرت ~۲۲ کامپوننت به `t()`: shell، امروز، کارها، تقویم، دستیار، برنامه، تمرکز، مالی، تنظیمات، ثبت سریع، جزئیات، آیتم کار، پالت، پروفایل، ظاهر، یادآور، اتصال‌ها، خالی‌حالت، ورود
- `formatNum/tf/longDate/monthTitle` — ارقام و تاریخ دوزبانه

## ۴) تقویم دوگانه (اولویت ۳)
- calendar-view بازنویسی: ۳ حالت شمسی / **دوگانه** (شمسی بزرگ پررنگ با رنگ تأکید + میلادی کوچک خاکستری انگلیسی) / میلادی
- عنوان ماه دوزبانه، سرستون‌های هفته per-mode، فلش‌های جهت‌آگاه RTL/LTR، پنل روز دوزبانه

## ۵) ماژول مالی (اولویت ۵)
- Prisma: `FinanceAccount` + `FinanceTransaction` (+ روابط User) — db push موفق
- `src/lib/finance/{core,server,exporters,client}.ts` — محاسبات خالص + لایه سرور با اعتبارسنجی + خروجی‌سازها
- API: accounts / accounts[id] / transactions / transactions[id] / export (csv,xls,json,txt)
- نمای مالی: مانده کل، درآمد/هزینه/خالص، حساب‌ها، نمودار دسته‌ها، تراکنش‌ها با حذف، فرم ثبت (۳ نوع)
- PDF: چاپ مرورگر از نمای گزارش (پشتیبانی کامل RTL)

## ۶) پیامک بانکی SMS (اولویت ۶)
- `src/lib/sms/parser.ts` — نرمال‌سازی ارقام/جداکننده، ۲۰ بانک، فعل/مبلغ/موجودی/کارت ماسک‌شده/تاریخ شمسی-میلادی؛ استراتژی دومرحله‌ای خط/بلوک
- API: `/api/sms/import` دو مرحله‌ای (پیش‌نمایش → ثبت با رضایت `sms_consent` + ضدتکرار SHA-256)
- UI: پنل SMS در نمای مالی (رضایت + چسباندن + تحلیل + تأیید)
- کاتالوگ اتصال‌ها: ورودی `sms_android` با ۶ افشای شفافیت

## ۷) تنظیمات کامل (اولویت ۴)
- نمای تنظیمات با ۱۰ دسته: حساب کاربری (نام/رمز/خروج)، ظاهر (تم/اکسنت/اندازه/جلوه‌ها/آب‌وهوا/اتصال‌ها)، هوش مصنوعی (موتور/Endpoint/تست/کلید قطع/مصرف)، زبان و تقویم، صدا، یادآورها، دسترسی‌ها (اعلان/میکروفون)، حریم خصوصی (مصرف + حق فراموشی دومرحله‌ای)، داده‌ها (Export/Import/Backup/Restore + خروجی مالی)، درباره
- ProfileChip → تنظیمات؛ ردیف‌های پروفایل بازاستفاده شدند
- API: `/api/data/export|import|delete-all` (same-origin + rate limit + تأیید متنی)

## ۸) Ambient Experience Layer (اولویت ۸)
- هویت زنده ۸ حالته: idle / breathing (خوش‌آمد، خودبازگشت ۴٫۲s) / glow (جشن تکمیل کار) / pulse (یادآوری) / listening / thinking / streaming / speaking
- Engine: `TRANSIENT_ORB` با خودبازگشت زمان‌دار؛ CSS تازه برای ۳ حالت (فقط transform/opacity)
- اتصال‌های معنایی: ورود → breathing؛ تکمیل کار (تک/چت) → glow؛ یادآوری → pulse؛ صدا/چت مثل قبل

## ۹) رفع عیب‌ها
- **نصب خالی قابل ورود نبود**: `ownerSetupPending` اکنون DB خالی را هم راه‌اندازی می‌شمارد؛ setup نگه‌دارنده را می‌سازد (ادعای اتمیک sentinel حفظ شد)
- الگوهای `\b` فارسی در مسیریاب نیت (JS \b با حروف فارسی کار نمی‌کند)
- ZWNJ در الگوها (`می‌تونی`)
- پارسر SMS: جداکننده هزارگان ٬ / کارت ماسک‌شده / پیامک چندخطی
- خروجی صوتی lang-aware در چت
