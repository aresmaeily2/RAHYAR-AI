# 03 — بک‌اند، دیتابیس و AI (Agent 3) — ممیزی + اصلاحات R2

## دیتابیس
- ۱۴ جدول؛ WAL فعال؛ pragmas: busy_timeout=5000، foreign_keys، synchronous=NORMAL؛ pool=1 (تک‌نویسندهٔ SQLite — صحیح).
- ایندکس‌ها مناسب ([userId,status,dueDate] و…)؛ cascadeهای user-owned؛ ActionLog با idempotencyKey یکتا.
- پول `Float` برای مبالغ: با سقف ≤1e15 و اعداد صحیح ریالی، ریسک دقت «پایین ولی صفر نیست» — **پذیرفته‌شده با مستند** (پیشنهاد آینده: Int).
- مهاجرت: `db push` بدون دایرکتوری migrations — قابل قبول برای تک‌نود؛ نسخهٔ پشتیبان DB: `scripts/backup-db.sh` (VACUUM INTO).

## AI — حکم واقعی‌بودن (بدون ساختگی)
- مسیر z-ai = فراخوانی واقعی SDK (`client.chat.completions.create`)، بدون متن کنسروی. `/etc/.z-ai-config` موجود (فقط stat — محتوا خوانده نشد).
- **اثبات زندهٔ R2**: پیام «سلام رهیار! …» → پاسخ واقعی مدل در ۲۲۷ نویسه (اسکرین‌شات `02-chat-real-ai-fa.png` + ویدئو). برچسب `mode` اکنون بازتاب موتور واقعی است (B-5).
- fallback قواعد محلی **صریحاً خود-برچسب‌گذاری** می‌شود («در حالت قواعد محلی هستم…») — هرگز به‌عنوان پاسخ مدل نمایش داده نمی‌شود.
- سقف‌ها: user 60/day، 900/month، system 300/day، ورودی 24k، خروجی 4k + RL 10/min + global 30/min + kill-switch.
- streaming SSE: meta→delta→done، مهار خروجی با cancel بالادست، حالا با قطع کلاینت (B-14) و ثبت مصرف شاخهٔ محلی (B-4).

## مالی
- محاسبهٔ موجودی صحیح (opening + درآمد − هزینه − خروج/ + ورود انتقال)؛ بدون N+1؛ بودجه: ماه تهران، هشدار ≥۸۰٪، over کامل.
- انتقال: دو حساب متمایز و متعلق به کاربر؛ dedup با `@@unique([userId,externalRef])`؛ export CSV با BOM و گارد formula-injection.
- B-7 (حذف حساب → جابه‌جایی موجودی counter-account): **پذیرفته‌شده با مستند** (نیازمند طراحی مجدد انتقال‌ها)؛ B-6 فوق.
