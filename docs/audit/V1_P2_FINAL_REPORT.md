### نقص‌های واقعی که در همین بخش پیدا و رفع شد (۴ مورد — همه با آزمون زندهٔ مجدد)
1. **undo در مسیر زنده هرگز fire نمی‌شد**: اکشن‌ها به‌صورت wrapper JSON ذخیره می‌شوند ولی `extractUndoable` فقط آرایهٔ خام می‌پذیرفت → مدل آزاد بود «حذف شد» بگوید در حالی که رکورد در DB می‌ماند (دقیقاً نقص P8). → `ccca074`
2. **لغوِ تکراری رکورد بی‌ربط حذف می‌کرد** (نقض مستقیم معیار مالک؛ در اجرای دوم مشاهده شد: «جلسه پروژه» حذف شد) → نیم‌فاصلهٔ «آخرین هدف» + پاسخ صادقانهٔ «چیزی برای انصراف نبود» → همان commit
3. **گارد صداقت ادعاهای حذف/plan را نمی‌گرفت** (P8-7a: مدل ادعای «حذف شد» با اکشن ok:false) → الگوهای حذف/مرتب اضافه + گیت پیام کنش‌محور (رفع false-positive روی پرسش خواندنی — یافتهٔ S5) → `d86af40`
4. **پسوند تقلیدی «(اکشن‌ها اجرا شد)»** در پاسخ‌های بدون اکشن → حذف خودکار → همان commit
+ رفع race در خودِ کد undo (deleteMany بدون throw) قبل از commit.
