## ۲. درخواست صریح دسترسی به دستگاه (نیاز مالک)

برای خروج از وضعیت BLOCKED، یکی از این مسیرها لازم است:

1. **گوشی اندروید واقعی (پیشنهادی: Android 10+) که مالک خودش آزمون کند** — بستهٔ تحویل شامل APKهای نصب‌پذیر نسخهٔ ۲.۴.۰ + جدول آزمون ۲۰-مرحله‌ای + فرم ثبت نتایج است؛ مالک/همکارش مراحل را اجرا و ویدئو + logcat را برمی‌گرداند. سریع‌ترین مسیر پذیرش واقعی.
2. **اتصال adb از راه دور به سندباکس** (مثلاً `adb connect <device-ip>:5555` از طریق tunnel) — در این صورت سناریوها این‌جا اجرا و logcat/ویدئو گرفته می‌شود.
3. **اعطای credentials پوش GitHub به این session** — جدا از دستگاه، برای انتشار شاخهٔ `v1/voice-acceptance` (هم‌اکنون push بدون credentials ممکن نیست؛ مانع جداگانه ثبت شده).
