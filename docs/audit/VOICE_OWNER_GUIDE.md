# راهنمای نصب و استفادهٔ صوتی — مالک (V1، v2.4.0)

## الف) نصب

1. APK را از بستهٔ تحویل بردارید: `download/RahyAr-V1/apks/Rahyar-user-v2.4.0-release.apk`
   (نسخهٔ مالک با امکانات کامل: `Rahyar-owner-v2.4.0-release.apk`)
2. **توجه — تغییر گواهی:** گواهی امضای F7 در سندباکس از بین رفته بود (خارج از Git بود و با بازیافت محیط پاک شد). APKهای v2.4.0 با **گواهی جدید** (`CN=RahyAr Release V1`) امضا شده‌اند؛ اگر نسخهٔ قبلی نصب است، اول **حذف** کنید سپس نصب (نصب روی نسخهٔ قبلی با خطای «امضای ناسازگار» رد می‌شود).
3. SHA256 هر APK در `SHA256SUMS.txt` بسته است — قبل از نصب تطبیق دهید:
   `sha256sum -c SHA256SUMS.txt`

## ب) شروع

- اپ با **رابط محلی آفلاین** باز می‌شود (بدون سرور، بدون حساب).
- برای استفادهٔ متصل (دستیار کامل با مدل): تنظیمات → «ورود به سرور» → نشانی سرور + حساب شما.

## ج) صحبت با رهیار

### حالت محلی (بدون اینترنت)
- دکمهٔ میکروفون شناور (پایین-راست) → لمس → اجازهٔ میکروفون → بگویید:
  - «وظیفه اضافه کن گزارش ماهانه»
  - «یادم بیار که دارو بخورم»
  - «هزینه ۱۵۰ هزار تومان خرید» → **تأیید می‌خواهد** («ثبت شود؟») → بله/نه
  - «این هزینه را ثبت نکن، منصرف شدم» → هیچ چیزی ثبت نمی‌شود
  - «گزارش مالی» / «برنامه امروز چیست» / «امروز چندمه» / «چیکار می‌تونی» / «لغو»
- زبان صوت و **سرعت خواندن**: تنظیمات → «دستیار صوتی».
- اگر دستگاه سرویس تشخیص گفتار ندارد: همان پنل، تایپ کنید (همان مسیر پارسر).

### حالت متصل (دستیار کامل)
- در نمای «دستیار» دکمهٔ میکروفون کنار جعبهٔ پیام → بگویید؛ **متن بلافاصله ارسال می‌شود** و پاسخ صوتی می‌شنوید؛ **بعد از هر پاسخ صوتی، گوش دادن خودکار ادامه می‌یابد** (مکالمهٔ پیوسته).
- قطع خواندن: لمس میکروفون هنگام خواندن (یا دکمهٔ قطع پاسخ) — خواندن فوراً قطع و شنود شروع می‌شود.
- تنظیمات → «صدا و گفتار»: پاسخ گفتاری (روشن/خاموش)، **زبان ورودی صوتی** (هم‌زبان رابط/فارسی/انگلیسی)، **سرعت خواندن** (۰٫۵ تا ۲٫۵).
- سناریوی چندمرحله‌ای:
  - شما: «برای فردا یادآوری بساز» → رهیار: «چه ساعتی؟» → شما: «ساعت ۹» → … → «یادآوری ثبت شد.»
  - شما: «۱۵۰ هزار تومان برای خرید هزینه کردم» → رهیار: «به کدام حساب؟» → شما: «بله، بانک ملت» → «انجام شد — ثبت شد».

### Wake Word (اختیاری — فقط حالت محلی)
- تنظیمات → «فعال‌سازی سلام رهیار» → اعلان ماندگار ظاهر می‌شود؛ بگویید **«سلام رهیار»** → اپ باز می‌شود و شنود شروع می‌شود (اگر میکروفون قبلاً اجازه گرفته باشد).
- خاموش‌کردن در همان تنظیمات — همه‌چیز فوراً متوقف می‌شود.

## د) اگر چیزی کار نکرد

| نشانه | علت رایج | اقدام |
|---|---|---|
| «سرویس تشخیص گفتار روی این دستگاه نصب نیست» | دستگاه بدون Google/Speech service | نصب/به‌روزرسانی Google app + «Speech Services by Google» |
| صدای فارسی ندارد | موتور TTS بدون بستهٔ فارسی | Settings گوشی → Text-to-speech → زبان فارسی را نصب کنید؛ یا موتور TTS فارسی نصب کنید |
| «اجازهٔ میکروفون داده نشد» | رد قبلی | Settings گوشی → Apps → رهیار → Permissions → Microphone |
| نصب رد شد | APK قدیمی با گواهی دیگر | حذف نسخهٔ قبلی، نصب دوباره |
