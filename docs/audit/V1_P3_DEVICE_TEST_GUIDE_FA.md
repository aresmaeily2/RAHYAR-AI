# RahyAr V1-P3 — راهنمای نصب و آزمون روی گوشی واقعی (فارسی)

> نسخهٔ APK: **2.4.0** — versionCode **28** (کاربر) / **29** (مالک) — از commit نهایی `68db1a7` شاخهٔ `v1/voice-acceptance`
> حداقل اندروید: **7.0 (API 24)** | بستهٔ آزمون: `download/RahyAr-V1-P3/APK/`
> وضعیت این راهنما: آماده برای آزمون مالک — آزمون واقعی روی دستگاه هنوز **BLOCKED** است (سندباکس بدون adb/دستگاه).

## ۱) نصب

1. APK مناسب را روی گوشی منتقل کنید:
   - برای آزمون عادی: `Rahyar-v2.4.0-vc28-user-release.apk` (بستهٔ «رهیار»)
   - برای حساب مالک با ویژگی‌های مدیریتی: `Rahyar-v2.4.0-vc29-owner-release.apk` (بستهٔ «رهیار مالک»)
2. «اجازهٔ نصب از منابع ناشناس» را برای مرورگر/فایل‌منیجر فعال کنید و فایل را نصب کنید.
3. **توجه به گواهی امضا**: گواهی release نسخهٔ P3 **همان گواهی نسخهٔ P2** است (`CN=RahyAr, O=RahyAr, C=IR` — SHA-256 گواهی: `598facd4…`)؛ بنابراین نصب روی نسخهٔ ۲.۴.۰ قبلی **به‌صورت آپدیت** انجام می‌شود و داده‌ها می‌مانند. اگر نسخهٔ قدیمی‌تر (۲.۱/۲.۲/۲.۳) با کلید دیگر نصب است، ابتدا حذف نصب لازم است.
4. بررسی صحت فایل قبل از نصب (اختیاری): مقدار SHA-256 هر APK در `SHA256SUMS` بستهٔ تحویل ثبت شده است.

## ۲) آماده‌سازی

1. سرور RahyAr (production یا تونل اختصاصی مالک) در دسترس باشد؛ آدرس را در تنظیمات برنامه وارد کنید و وارد شوید.
2. در اولین اجرای چت صوتی، **اجازهٔ میکروفون** را «Allow» بزنید (سناریوی ۱ آزمون پایین، هر دو حالت را می‌سنجد).
3. برای گزارش‌گیری: `adb logcat -v time > logcat.txt` (یا در تنظیمات توسعه‌دهندهٔ گوشی، باگ‌ریپورت) + ضبط ویدیوی صفحه در طول آزمون.

## ۳) مسیر کامل صوتی (معیار اصلی پذیرش)

> کاربر صحبت می‌کند → **STT** → تشخیص قصد → **Agent** → اجرای اکشن واقعی روی DB → بررسی نتیجه → **TTS** به گوش کاربر

| # | گام | معیار قبول |
|---|---|---|
| 1 | نگه‌داشتن دکمهٔ میکروفون و گفتن «فردا ساعت ۹ یادآوری کن با دکتر تماس بگیرم» | متن فارسی درست در کادر (STT)، پاسخ صوتی فارسی (TTS)، یادآور در صفحهٔ یادآورها با ساعت ۰۹:۰۰ تهران ثبت شده باشد |
| 2 | گفتن «امروز ۱۵۰ هزار تومان خرید کردم» | پیشنهاد تأیید (بدون نوشتن)؛ موجودی تغییر نکرده باشد |
| 3 | گفتن «بله» | نوشتن واقعی ۱۵۰٬۰۰۰؛ موجودی کم شود؛ پاسخ «انجام شد» |
| 4 | بلافاصله گفتن «منصرف شدم» | حذف همان رکورد تازه با اعلام نام/مبلغ دقیق (لِین undo قطعی) |
| 5 | دوباره گفتن «منصرف شدم» | پاسخ صادقانهٔ «چیزی برای انصراف نبود» و حذف هیچ رکورد دیگری |
| 6 | گفتن «فردا ساعت چند قرار دارم؟» | خواندن یادآورهای واقعی DB با ساعت تهران |

## ۴) سناریوهای الزامی مأموریت (۸ مورد)

| # | سناریو | معیار قبول |
|---|---|---|
| 1 | اجازه/رد مجوز میکروفون | Allow → ضبط شروع می‌شود؛ Deny → پیام راهنمای صادقانه و عدم ضبط (بدون کرش) |
| 2 | قطع و وصل اینترنت | آفلاین → پیام خطای صادقانه، صف/تلاش مجدد؛ آنلاین شدن → ادامهٔ کار بدون از دست رفتن داده |
| 3 | توقف و شروع دوبارهٔ مکالمه | بستن صفحه و بازگشت → تاریخچه درست نمایش داده شود (بدون JSON خام — رفع D-6) |
| 4 | مکالمهٔ پیوسته | چند سؤال/فرمان پشت‌سرهم بدون نیاز به لمس دوباره؛ شفاف بودن نوبت‌ها |
| 5 | بَرج-این | حرف زدن هنگام TTS → پخش متوقف و گوش به فرمان جدید می‌رود |
| 6 | TTS فارسی/انگلیسی | انتخاب زبان in تنظیمات صوتی؛ سرعت 0.5–2.5 اثر واقعی دارد |
| 7 | خطای STT/TTS | سکوت/نویز → پیام صادقانه «متوجه نشدم»؛ خرابی موتور → پیام خطا، بدون ادعای موفقیت |
| 8 | یادآور + هزینه با تأیید | ایجاد یادآور و ثبت هزینه با جریان تأیید کامل بند ۳ |
