# سیستم طراحی رهیار — «شیشه‌ی آرام» (Calm Glass) نسخه ۴.۰

> تنها منبع حقیقت تصمیم‌های طراحی. هر کامپوننت جدید **باید** فقط از این توکن‌ها تغذیه کند.
> نوشتن مقدار hardcode برای رنگ/فاصله/سایه/بلور در صفحات ممنوع است.

---

## ۱. فلسفه و جهت بصری

رهیار یک «همراه هوشمند آرام» است، نه یک داشبورد مدیریتی. زبان بصری محصول از سه اصل ساخته شده:

1. **سکوت بصری** — سلسله‌مراتب با فضای خالی و تایپوگرافی ساخته می‌شود، نه بوردر و کادر.
2. **شیشه‌ی واقعی و ظریف** — عمق از بلورِ ملایم و نور می‌آید؛ هرگز اغراق‌آمیز نیست.
3. **طبیعتِ زنده اما بی‌آزار** — پس‌زمینه چندلایه (مش رنگی + صحنه SVG + نویز + ذرات) در آلفای ۳–۷٪ فقط «حس» می‌سازد.

الهام‌ها (بدون کپی): Apple Journal/Reminders/Health (سکوت و سلسله‌مراتب)، Things 3 (ریتم فهرست)،
Linear (تراکم حرفه‌ای)، Arc/visionOS (شیشه و عمق)، Calm/Reflect (تنفس و آرامش)،
Fantastical (تقویم)، Raycast (پالت دستور)، Bixa.ai (فضای تنفس).

## ۲. ساختار فایل‌ها

| فایل | نقش |
|---|---|
| `src/styles/tokens.css` | توکن‌های خام: تایپ، شعاع، فاصله، بلور، عمق، حرکت، شفافیت، خط، هاله |
| `src/styles/themes.css` | ۸ تم جهان‌بینی × روشن/تیره + ۷ اکسنت + نگاشت به توکن‌های shadcn |
| `src/styles/glass.css` | سطوح شیشه (۱–۳)، کارت شناور، کنترل برند، چیپ‌های توکن‌دار |
| `src/styles/motion.css` | پس‌زمینه زنده، ذرات، گلبرگ/برگ ریزان، keyframes مشترک، حالت تمرکز، مقیاس متن |
| `src/app/globals.css` | اتصال لایه‌ها + @font-face + نگاشت Tailwind (`@theme inline`) + پایه |

قاعده cascade: کل قواعد `glass.css` و `motion.css` داخل `@layer components` هستند تا
یوتیلیتی‌های Tailwind (مثل `fixed`) همیشه بتوانند بازنویسی‌شان کنند.

## ۳. توکن‌ها (گزیده)

### رنگ — دو محور مستقل
- **data-theme** (جهان): `ocean` اقیانوس، `forest` جنگل، `aurora` شفق، `sunset` غروب،
  `night` شب (OLED)، `minimal` مینیمال، `sakura` شکوفه، `autumn` پاییز.
  هر تم تعیین می‌کند: کاغذ روشن/تیره، ۳ رنگ صحنه، ۲ هاله محیطی، رنگ تزئینی SVG، تینت شیشه، رنگ‌های نمودار.
- **data-accent** (تعامل): `teal، blue، violet، green، orange، pink، gold` — مقیاس ۳۰۰…۷۰۰
  + `--ax-ink` (متن روی سطح اکسنت در تیره) و `--ax-on` (متن روی دکمه پرشده).

نگاشت‌های کلیدی مشتق‌شده:
`--primary` (اکسنت‌۶۰۰ روشن / اکسنت‌۴۰۰ تیره)، `--primary-text` (متن رنگی با کنتراست AA:
اکسنت‌۷۰۰ روشن / اکسنت‌۳۰۰ تیره)، `--glow-brand` (هاله برند با شدت توکن‌محور)،
`--shadow-soft/lift/float/overlay` (از ۴ سطح elevation).

**قاعده کنتراست:** متنِ رنگی روی کاغذ همیشه از `--primary-text` استفاده کند نه `--primary`؛
`text-muted-foreground` بدون آلفای کاهنده (الگوی `/70` ممنوع برای متن محتوایی).

### تایپوگرافی
- متن: **Vazirmatn Variable** (`--font-body`)، عنوان: **Estedad Variable** (`--font-display`).
- مقیاس نرخ ~۱٫۲۲: `--text-2xs 10px … --text-2xl 24px` + `--text-hero` سیال.
- لایing: tight 1.35 / normal 1.7 / relaxed 1.9؛ `--tracking-tight -0.01em`.
- اعداد: `.tnum` برای همه ارقام جدولی.
- اندازه متن کاربر: `data-textscale` با ۴ گام (93.75٪ تا 125٪) — WCAG 1.4.4.

### شعاع
`--radius` مبنا ۱۴px؛ مقیاس xs(6)…3xl(28) + full. کارت‌های اصلی: `rounded-3xl`، کنترل‌ها: `rounded-2xl/xl`.

### بلور و سطوح شیشه
| سطح | بلور | اشباع | آلفا | مصرف |
|---|---|---|---|---|
| glass-1 | 10px | 1.3 | 0.50 | چیپ و کنترل ریز |
| glass-2 | 18px | 1.45 | 0.62 | کارت‌ها |
| glass-3 | 28px | 1.6 | 0.74 | هدر چسبان، دیالوگ |

### عمق (Elevation) — ۴ سطح
هر سطح = سایه کلیدی + سایه محیطی؛ سطح برند علاوه بر آن `--glow-soft` می‌گیرد.

### حرکت
- مدت‌ها: instant 120 / fast 160 / base 240 / slow 420 / scene 800 (ms).
- منحنی‌ها: `--ease-standard` (امضا)، `--ease-emphasized` (pop)، `--ease-spring` (FAB)، `--ease-exit`.
- معادل‌های Framer در `src/components/ara/motion.ts` (`viewFade`, `listItem`, `popIn`, `dialogIn`, سه spring).
- همه حلقه‌ها فقط transform/opacity؛ همه زیر `prefers-reduced-motion` و سوییچ کم‌مصرف (`ara-no-fx`) خاموش می‌شوند.

## ۴. کامپوننت‌های پایه

- `.glass-card` (+`glass-hoverable`) — کارت شیشه‌ای با خط داخلی، بازتاب، عمق، هاله hover
- `.glass-chip` / `.glass-panel` / `.glass-overlay` — سطوح ۱/۳/دیالوگ
- `.ara-float` / `.ara-float-primary` / `.ara-press` — کنترل شناور + واریانت برند + فشار الاستیک
- `.chip-accent` / `.chip-warn` / `.chip-danger` — چیپ‌های رنگی توکن‌دار
- `.ara-skeleton` — اسکلت شیمردار (Spinner ساده فقط برای busy کوچک داخل دکمه)
- `.ara-bubble-user`, `.ara-md`, `.ara-gradient-text`, `.ara-stream-cursor`, `.ara-live-dot`, `.ara-typing-dot`
- `<AiOrb>` (idle/thinking) + `<VoiceWave>` — هویت دستیار
- `<EmptyState art="…">` — ۱۲ تصویرسازی SVG: sun, leaf, moon, wave, calendar, chat, search, bell, memory, settings, cloud-off, success
- `<AmbientScene>` — صحنه SVG پارامتریک هر تم + نویز feTurbulence + ۵ ذره نور

## ۵. قواعد آیکون و تصویرسازی

- مجموعه واحد: **Lucide**، stroke یکدست 1.75 (سراسری روی `svg.lucide`)، سایزهای ۳٫۵/۴/۴٫۵/۵.
- تصویرسازی‌ها فقط SVG درون‌خطی با رنگ‌های توکن (`--deco`, `--primary`, `--success`, `--destructive`)؛
  **بدون Emoji، بدون PNG تزئینی**. عناصر طبیعت پارامتریک تولید می‌شوند (گلبرگ/برگ با حلقه‌های آرایه).

## ۶. قواعد شیشه (چه چیزی شیشه است؟)

شیشه فقط برای: سایدبار، داک ناوبری، هدر چسبان، FAB، دیالوگ/شیت، کارت‌های اصلی خانه،
پالت دستور، تایمر تمرکز. فهرستِ ردیفِ کار شیشه نیست (کارایی GPU + خوانایی) — فقط hover سطح ۲ می‌گیرد.

هر سطح شیشه ۸ خصیصه دارد: بلور طبیعی، شفافیت کنترل‌شده، خط داخلی (inset ring)،
بازتاب نرم (::before مورب)، عمق، سایه شناور، شکست نور (خط روشن لبه بالا)، هاله محیطی برند.

## ۷. پس‌زمینه زنده (Living Background)

چهار لایه ثابت (به‌جز ذرات/گلبرگ):
1. مش رنگی ۳ نقطه‌ای از رنگ‌های صحنه تم (۴–۶٪)
2. صحنه SVG تم (موج/کوه/روبان/تپه/ماه/حلقه/شکوفه/خزان) با بلور ۳۴
3. گرین نویز feTurbulence در آلفای ۳٪ (mix-blend overlay)
4. دو هاله شناور (چرخه ۳۶–۴۴ ثانیه) + ۵ ذره نور + گلبرگ/برگ ریزان در تم‌های شکوفه/پاییز

هزینه فریم: صحنه‌ها و نویز ایستا هستند؛ فقط عنصرهای متحرک با transform حرکت می‌کنند (GPU).
در حالت تمرکز (`data-focus-mode="on"`) همه حلقه‌های محیطی می‌ایستند و آلفاها نصف می‌شوند.

## ۸. دسترس‌پذیری — قواعد الزامی

- هدف لمسی ≥ 44px (`--touch-min`)، فوکوس‌رینگ سراسری `:focus-visible`.
- کنتراست AA: متن رنگی فقط با `--primary-text`؛ ممنوعیت آلفای کاهنده روی متن محتوایی.
- `aria-current` برای ناوبری، `role=radiogroup` برای انتخاب‌گرها، `aria-live` برای وضعیت چت/یادآور.
- کلیدهای میانبر: ۱–۵ نما، N کار جدید، / پالت، D تم، ⌘K پالت.
- کاهش حرکت: CSS جهانی + `useMotionSafe()` در Framer.

## ۹. performance

- فقط transform/opacity در انیمیشن‌ها؛ صحنه SVG ایستا.
- بلورها محدود به سطوح منتخب؛ در `ara-no-fx` و focus-mode حذف می‌شوند.
- نماهای غیرپیش‌فرض با `next/dynamic` + اسکلتون (کد اسپلیت).
- فونت‌های Variable با preload — یک فایل به‌جای ۶ وزن.
