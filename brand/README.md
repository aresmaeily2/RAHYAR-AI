## PNG شفاف 1024×1024
`png/rahyar-*-1024.png` — رندرشده از SVG با sharp (librsvg). نسخه‌های 48 و 24 پیکسلی برای آزمون خوانایی اندازهٔ کوچک موجود است (`rahyar-mark-solid-48.png`, `-24.png`).

## توکن‌های برند
- گرادیان: `#7C5CFF` (بنفش) → `#F062A4` (صورتی) → `#2FD8C8` (فیروزه‌ای) — زاویه ۱۳۵°
- نشان R: خط سفید، ضخامت ۹/۱۰۰، سرِ خط گرد — مونوگرام هندسی اصلی
- رنگ عمیق پس‌زمینهٔ اسپلش: `#0B1020`
- گوشه‌گردی نشان: ۲۲٪ قطر

## منشأ و مجوز
- همهٔ واریانت‌ها **اثر هنری اصلی و اختصاصی پروژهٔ RahyAr** هستند که برای این پروژه طراحی و به‌صورت برداری (SVG) ساخته شدند؛ هیچ لوگو، فونت یا اثر ثالثی در آن‌ها استفاده نشده است.
- متن‌های wordmark با فونت سیستمی رندر می‌شوند (بدون جاسازی فونت).
- مالکیت اثر با مالک پروژه است. شباهت احتمالی مونوگرام R با نشان‌های دیگر به‌صورت رسمی بررسی نشده و هیچ ادعای انحصاری ثبت‌شده‌ای وجود ندارد؛ پیش از استفادهٔ تجاری، جست‌وجوی علائم تجاری توصیه می‌شود.
- نام برند در همهٔ نسخه‌ها یکسان است: **RahyAr AI**.
